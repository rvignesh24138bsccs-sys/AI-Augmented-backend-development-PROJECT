FitTrack AI - Personalized fitness recommendations powered by AI. 
Description
The FitTrack AI   backend is a secure, scalable, and AI-powered RESTful application developed to simplify workout tracking and provide intelligent fitness recommendations. Built using Node.js, Express.js, MongoDB, and Mongoose, the backend exposes REST APIs that enable secure user authentication, workout management, workout searching, and AI-assisted fitness guidance.
The application follows the Model-View-Controller (MVC) architecture, making the project modular, maintainable, and scalable. User authentication is implemented using JSON Web Tokens (JWT), while passwords are securely encrypted using bcrypt.js before storage in MongoDB. Every protected API validates the JWT token through middleware before allowing access to sensitive resources.
One of the key features of the project is its integration with Google Gemini AI, which provides personalized workout recommendations based on a user's age, fitness goals, and workout experience. The AI module also generates fitness insights by analyzing workout statistics such as total workouts completed, average workout duration, and calories burned.
The backend returns standardized JSON responses, making it suitable for integration with web, mobile, and third-party applications. Proper error handling, input validation, route protection, and modular service implementation ensure the application is reliable, secure, and easy to extend.

Rahul is a fitness enthusiast who exercises regularly but records his workouts manually using notebooks and spreadsheets. Although he maintains consistency in his fitness routine, he finds it difficult to organize workout history, monitor progress, and determine whether his exercise habits align with his fitness goals. He also lacks professional guidance when deciding which workouts are best suited for his current fitness level.

Solution
The FitTrack AI   provides a centralized backend system where users can securely register, authenticate, and manage workout records. Users can add, update, delete, retrieve, and search workouts through RESTful APIs. By integrating Google Gemini AI, the application analyzes user information and workout statistics to generate intelligent workout recommendations and personalized fitness insights.
The backend follows industry-standard security practices including JWT authentication, password hashing, middleware-based authorization, centralized error handling, and MongoDB schema validation.

Epic 1: Project Architecture


The FitTrack AI   follows a layered architecture based on the MVC (Model–View–Controller) design pattern. The application separates routing, business logic, database interaction, middleware, and AI services into independent modules, making the project easier to maintain and scale.
When a client sends an HTTP request, the Express server receives it and forwards it to the corresponding route. Protected routes first pass through the authentication middleware, which validates the JWT token before granting access. Controllers process validated requests and invoke business logic or AI services as required. Database interactions are handled through Mongoose models, while Google Gemini AI is accessed through a dedicated service layer. Finally, the controller returns a structured JSON response to the client.
This layered approach improves modularity, security, and maintainability while ensuring that each component has a single responsibility.
